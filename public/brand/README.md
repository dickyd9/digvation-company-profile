# Digvation Brand Assets

This directory contains the official web-ready Digvation assets supplied with the project.

- `logo/` — horizontal lockups used by the website in indigo and white
- `marks/` — marks used by the favicon, legal pages, and project preview
- `social/` — the Open Graph image used when a page is shared

Do not redraw, trace, stretch, skew, recolor, bevel, glow, or otherwise alter the logo artwork. Use the existing variants instead.
