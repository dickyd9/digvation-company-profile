# SEO Validation

## Market language reviewed

Current Indonesian search results and institutional language consistently use these concepts:

- digitalisasi bisnis
- proses bisnis
- pembuatan sistem informasi or sistem bisnis
- aplikasi perusahaan or aplikasi internal
- otomasi proses bisnis
- integrasi sistem
- dashboard monitoring and data analytics

The website uses these terms only where they match the page intent. No search-volume value is claimed because no verified Google Ads Keyword Planner export was available.

## Page intent

- `/`: partner digitalisasi bisnis and brand positioning.
- `/solutions`: commercial solution intent, including internal systems, web apps, automation, integration, data, and custom business needs.
- `/work`: project evidence and case-study intent.
- `/process`: confidence in engagement and delivery.
- `/about`: Digvation purpose and brand trust.
- `/contact`: high-intent conversation and inquiry.
- `/campaign/[slug]`: paid-acquisition intent, configurable `noindex`.

## Technical validation

- Unique title and description per primary route.
- Canonical URLs generated from the production site URL.
- Indonesian, English, and x-default alternates on paired routes.
- Open Graph and Twitter image metadata.
- Organization and Website schema site-wide.
- Service schemas on the inline Solutions directory.
- Breadcrumb and CreativeWork schemas on case studies.
- FAQ schema shares the same homepage source content.
- Generated sitemap and robots route.
- Noindex 404 and configurable noindex campaign routes.
- Permanent redirects from historical solution details to matching inline fragments.

## Follow-up with production data

After launch, use Search Console queries and qualified-inquiry data to refine wording. Validate search demand by page and conversion quality rather than adding repeated keywords to public copy.
