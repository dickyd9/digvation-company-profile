# Homepage Sections

The homepage follows one commercial sequence:

```text
Clarity -> Proof -> Relevance -> Process -> Action
```

## Current flow

1. **Minimal hero**: one problem-led proposition, one primary CTA, one quiet link to work, and deliberate whitespace.
2. **Featured work as proof**: actual optimized screenshots from live Digvation projects expand through large project-specific stages. No illustrative dashboard is used as evidence.
3. **How Digvation helps**: Build, Improve, Connect, Automate, and Understand expressed through five concise business actions. Details expand inline instead of creating a card grid.
4. **How Digvation works**: Understand, Shape, Build, Validate, Launch, and Improve in one connected sequence.
5. **Final CTA**: a human invitation to bring one business problem.

## Visual rules

- Use whitespace, typography, real screenshots, and dark/light rhythm before decoration.
- One section may carry one statement or one visual without filling every gap.
- The homepage stays selective. Client relationships and FAQ content must not be added unless they provide stronger evidence or remove meaningful conversion friction.
- Real work must never be presented through a generic fallback dashboard.
- Technology is supporting metadata, not the headline.
- No fake metrics, awards, testimonials, clients, results, or prices.
- Avoid em dashes in public copy.
- Animation must be quiet, progressive, and safe with reduced motion. Use masks, line wipes, image expansion, and purposeful route transitions instead of repeating the same fade-up.
- Do not add a slider unless a future content set genuinely requires horizontal exploration and includes discoverable controls.
